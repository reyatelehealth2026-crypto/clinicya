  • เข้าระบบ REYA ของร้านได้ (เช่น ชื่อร้าน.re-ya.com)

คำศัพท์ที่จะเจอ (เข้าใจง่ายๆ)
  • • Channel (แชนแนล) = "ช่องทาง" ของ LINE ที่ให้ระบบอื่นมาเชื่อมได้

1

สร้างบัญชี LINE Official Account

ถ้ามีอยู่แล้ว ข้ามไปขั้นที่ 2 ได้เลย

  1. 1.1 เปิดเว็บ manager.line.biz แล้วล็อกอินด้วยบัญชี LINE ส่วนตัว
  2. 1.2 กดปุ่ม "สร้างบัญชีใหม่ (Create)"
  3. 1.3 กรอกชื่อร้าน, ประเภทธุรกิจ (เลือก "ร้านขายยา/สุขภาพ") แล้วกดยืนยัน
  4. 1.4 เสร็จแล้วจะได้ LINE Official Account ของร้าน (มีชื่อขึ้นต้นด้วย @ เช่น @yourshop)
จำ Basic ID ไว้ — ชื่อที่ขึ้นต้นด้วย @ (เช่น @yourshop) จะใช้ในขั้นที่ 4
2

สร้าง Provider + เปิด Messaging API

"Provider" และ "Messaging API channel" คืออะไร และทำยังไง

เข้าใจ 2 คำนี้ก่อน (ง่ายๆ)
  • • Provider (ผู้ให้บริการ) = "เจ้าของ/บริษัท" ที่เป็นเจ้าของ LINE ร้านคุณ — เหมือนโฟลเดอร์ที่เก็บช่องทางต่างๆ ของร้านไว้รวมกัน ตั้งชื่อเป็นชื่อร้านหรือชื่อบริษัทก็ได้
  • • Messaging API channel = "ช่องทางให้ระบบอื่น (REYA) คุยกับ LINE ร้านได้" — เปิดอันนี้แล้วถึงจะได้รหัส 3 ตัวในขั้นที่ 3
วิธีที่แนะนำ (ง่ายสุด) — เปิดผ่าน OA Manager
  1. ก. เข้า manager.line.biz → เลือก OA ของร้าน → เมนู ตั้งค่า (Settings)
  2. ข. เลือกหัวข้อ Messaging API → กดปุ่ม "ใช้งาน Messaging API" (Enable / Use Messaging API)
  3. ค. ระบบจะให้เลือก Provider — ถ้ายังไม่มี ให้พิมพ์ชื่อร้าน/บริษัทเพื่อสร้างใหม่ → ยืนยัน
  4. ง. กรอกชื่อ-อีเมลผู้พัฒนา (ถ้าถาม) → ยอมรับข้อตกลง → เสร็จ! ระบบจะสร้าง channel ให้อัตโนมัติ
สำคัญมาก: เมื่อเลือก Provider ให้ดูแล OA แล้ว จะเปลี่ยนหรือยกเลิก Provider ทีหลังไม่ได้ — เลือกชื่อให้ถูก (ชื่อร้าน/บริษัทของคุณเอง อย่าไปเลือก provider ของคนอื่น)
อีกวิธี — สร้างจาก LINE Developers Console โดยตรง (สำหรับคนถนัดเทค)
  1. 1. เข้า developers.line.biz/console ล็อกอินด้วยบัญชี LINE เดียวกับที่สร้าง OA
  2. 2. กด Create a new provider → พิมพ์ชื่อร้าน/บริษัท → Create
  3. 3. ในหน้า provider กด Create a Messaging API channel
  4. 4. กรอกข้อมูล channel:
    • – Channel name (ชื่อ) — ห้ามมีคำว่า "LINE" และเปลี่ยนไม่ได้ภายใน 7 วันแรก
    • – Channel description (คำอธิบายสั้นๆ)
    • – Category / Subcategory (หมวดหมู่ — เลือก "ร้านค้า/สุขภาพ" ให้ใกล้เคียง)
    • – Email address (อีเมลติดต่อ)
    • – Region เลือก Thailand (ถ้ามีให้เลือก)
  5. 5. ติ๊กยอมรับข้อตกลง 2 ช่อง → Create
ถ้าร้านเคยเปิด Messaging API ไว้แล้ว ก็แค่เข้าไปที่ channel เดิมในขั้นที่ 3 ได้เลย ไม่ต้องสร้างใหม่

5

ตั้ง Webhook + ปิด Auto-reply + ทดสอบ

ขั้นสุดท้าย ให้ LINE ส่งข้อความเข้ามาที่ REYA

  1. 5.1 หลังบันทึกในขั้นที่ 4 การ์ดบัญชีจะมีช่อง Webhook URL — กดปุ่ม เพื่อคัดลอก (หน้าตาแบบ https://ชื่อร้าน.re-ya.com/webhook.php?account=1)
  2. 5.2 กลับไปที่ LINE Developers → แท็บ Messaging API → ช่อง Webhook URL → กด Edit → วาง URL ที่คัดลอกมา → Update
  3. 5.3 เปิดสวิตช์ "Use webhook" ให้เป็นสีเขียว (เปิด)
  4. 5.4 เลื่อนหา "Auto-reply messages" และ "Greeting messages" → กด Edit → ปิด (Disabled) ทั้งคู่ (เพื่อให้ REYA เป็นคนตอบแทน)

เสร็จแล้ว! ตอนนี้ลูกค้าทักเข้า LINE ร้าน จะเข้าระบบ REYA ทั้งหมด — ตอบแชต, ขายของ, สะสมแต้ม, จ่ายยา ได้ครบ

แก้ปัญหาที่เจอบ่อย

กดทดสอบแล้วขึ้น "เชื่อมต่อไม่สำเร็จ"

เกือบทุกครั้งเกิดจาก Channel Access Token คัดลอกไม่ครบ (รหัสยาวมาก) — กลับไปขั้นที่ 3 คัดลอกใหม่ทั้งหมด แล้ววางในขั้นที่ 4 อีกครั้ง · ตรวจ Channel Secret ด้วยว่าตรง

ทักไปแล้วบอทไม่ตอบ

เช็ค 3 อย่างในขั้นที่ 5: (1) Use webhook เปิดอยู่ไหม (2) Webhook URL วางถูกไหม (3) Auto-reply / Greeting ปิดแล้วหรือยัง — ถ้า Auto-reply ยังเปิด LINE จะตอบเองแทน REYA

หา "รหัส 3 ตัว" ไม่เจอ

Channel ID + Secret อยู่แท็บ Basic settings · Access Token อยู่แท็บ Messaging API เลื่อนลงล่างสุด แล้วกด Issue ถ้ายังไม่มี

มี LINE OA หลายอัน/ หลายสาขา

ทำซ้ำขั้นที่ 2–5 สำหรับแต่ละ OA ได้เลย ระบบ REYA รองรับหลายบัญชี LINE — แต่ละอันจะมี Webhook URL ของตัวเอง (เลข account ต่างกัน)
