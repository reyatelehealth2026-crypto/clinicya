## คลิป 1 — ให้แต้มสะสม (ขายหน้าร้าน)

**ปุ่มเริ่ม:** `🎁 ให้แต้ม (ขายหน้าร้าน)` (แถบซ้ายบน) → เรียกฟังก์ชัน `openGivePointsModal()`

ขั้นตอนที่อัดได้ (คลิกจริงทั้งหมด):

1. กดปุ่ม **🎁 ให้แต้ม (ขายหน้าร้าน)** → เปิด Modal **"ให้แต้มสะสม"**
2. กรอก **ยอดเงิน (฿) = 250** → ระบบคำนวณอัตโนมัติ **"≈ จะได้รับ 250 แต้ม"** (อัตรา 1 บาท = 1 แต้ม)
3. เลือก **วิธีชำระเงิน = 💵 เงินสด** (ไม่บังคับ)
4. กด **⚡ ให้ทันที** → ระบบบันทึกแต้มจริง

**ผลลัพธ์จริง (verified):**

- สถานะ **"ให้แต้มสำเร็จ +250 ⭐"**
- ยอดแต้มคงเหลือ **11,913 → 12,163 แต้ม**
- เลขที่รายการ **WI20260603-003**
- ระบบ **ส่งใบเสร็จแต้ม (LINE Flex) เข้าแชทลูกค้า** อัตโนมัติ และบันทึกในประวัติแต้ม

> มีอีกทางเลือกในจอเดียวกัน: **📷 สร้าง QR แทน** (`givePointsGenerate()`) ให้ลูกค้าสแกนรับแต้มเอง
> และช่อง **แต้มที่จะให้ (ระบุเอง)** สำหรับกำหนดแต้มตรง ๆ แทนการคำนวณจากยอดเงิน

## คลิป 2 — CRM HUD / ลูกค้า 360°

**ตำแหน่ง:** แผง **HUD** ฝั่งขวา (แท็บ `CRM` / `AI` / `เกมเพลส`)

สิ่งที่อัดได้ (ไล่จากบนลงล่าง):

- **Tier + แต้ม:** `Platinum` · ID 000001 · แต้มคงเหลือ (ตัวเลขใหญ่)
- **สถิติ:** `24 ออเดอร์` · `฿25,992.00 ยอดซื้อ` · `146 ข้อความ`
- **ข้อมูลลูกค้า:** ชื่อ / เบอร์โทร / ที่อยู่ (แก้ไขได้ inline ปุ่มดินสอ)
- **สถานะงาน:** dropdown (เช่น 🔴 ต้องดำเนินการ) + ปุ่ม **มอบหมายงาน**
- **TAGS:** แท็กความสนใจ (เช่น `สนใจสินคา_สนใจ`) + ปุ่ม **+ เพิ่ม Tag**
- **โน้ต:** โน้ตภายในทีม (ระบุผู้บันทึก + เวลา) + ช่องเพิ่มโน้ต
- **รายการล่าสุด:** ออเดอร์ย้อนหลัง `#49 ฿483.00` · `#47 ฿2,985.00` · `#45 ฿126.00`
- ปุ่มลัดท้ายแผง: **จ่ายยา** / **ให้แต้ม**

จุดขาย: เห็นลูกค้าครบ 360° ในจอเดียวขณะแชท ไม่ต้องสลับหน้า

## คลิป 3 — Quick Actions ในแชท

**ตำแหน่ง:** แถบเครื่องมือเหนือแชท

| ปุ่ม | การทำงาน (handler) |
|------|--------------------|
| งานด่วน | เมนูงานด่วน |
| ข้อมูลลูกค้า | แสดง HUD ลูกค้า |
| โน้ต | `ChatWorkflow.openNotes()` |
| **จ่ายยา** | `ChatWorkflow.openDispense()` |
| ออเดอร์ | `ChatWorkflow.openPath('/shop/orders?user_id=1')` |
| นัดหมาย | `ChatWorkflow.openPath('/appointments-admin?user_id=1')` |
| สินค้า | `ChatWorkflow.openPath('/inventory?tab=products')` |
| ส่งเมนู | `ChatWorkflow.sendMenu()` *(ส่งเมนูเข้าแชทลูกค้า — ระวัง side effect)* |

คลิปนี้โชว์ **Modal จ่ายยา** ที่เปิดจากปุ่ม **จ่ายยา**:

- หัวข้อ **"💊 จ่ายยา - customer"**
- ฟิลด์ **ชื่อร้าน** (ร้านยา) · **ผู้จ่ายยา** (Admin Admin)
- ช่อง **ค้นหายา (ชื่อ, SKU, บาร์โค้ด)**
- ตาราง **รายการยา** (เริ่มต้น 0 รายการ)
- **ชำระเงิน** (เงินสด) · **ยอดรวม ฿0** · ปุ่ม **ยืนยันจ่ายยา**

## คลิป 4 — ค้นหา/กรอง + มอบหมายงาน

**ตำแหน่ง:** แถบซ้าย (ค้นหา + ฟิลเตอร์) และ HUD (มอบหมายงาน)

ฟิลเตอร์ในแถบซ้าย 4 ตัว:

| ฟิลเตอร์ | ตัวอย่างตัวเลือก |
|----------|------------------|
| สถานะ | ทุกสถานะ / ยังไม่อ่าน / มอบหมายแล้ว |
| แท็ก | ทุกแท็ก / แท็กความสนใจสินค้าแต่ละตัว |
| สถานะงาน | 🔴 ต้องดำเนินการ / 🟢 ดำเนินการแล้ว / 📦 รอจัดส่ง / 🚚 ติดตามสถานะ / 💰 ติดตามบิล |
| ผู้รับผิดชอบ | มอบหมายให้ฉัน / ยังไม่มอบหมาย / รายชื่อทีม (Admin Admin, Atiruj RX, jamejame) |

สิ่งที่อัดได้:

1. เปลี่ยนฟิลเตอร์ **สถานะงาน → 🔴 ต้องดำเนินการ** → รายการแชทถูก **กรองทันที** (เหลือเฉพาะที่ตรงสถานะ)
2. กดปุ่ม **มอบหมายงาน** (HUD) → `HUDMode.showAssignModal()` → เปิด Modal **"👥 มอบหมายงาน (เลือกได้หลายคน)"** พร้อมปุ่ม ยกเลิก / มอบหมาย
3. ช่องค้นหาด้านบน: `ค้นหาชื่อ, ข้อความ, แท็ก...` + ปุ่ม **อ่านทั้งหมด**

## หมายเหตุการส่งมอบ & ความปลอดภัยข้อมูล

- คลิปทั้งหมดใช้ **ข้อมูล tenant จริง** (ชื่อลูกค้า, เบอร์โทร, ยอดซื้อ ฯลฯ) ตามที่สั่ง **ไม่เบลอ** — ควรใช้ภายในทีมที่มีสิทธิ์เห็นข้อมูลจริงเท่านั้น (อิง PDPA)
- คลิป 1 มีการ **เพิ่มแต้มจริง 250 แต้ม** ให้ลูกค้า `customer` (ID 000001) และ **ส่ง LINE จริง** — เป็นการสาธิตบนข้อมูลจริงตามคำสั่ง
- ไฟล์ GIF ต้นฉบับอยู่ใน **Chrome downloads ของเครื่องที่อัด** ย้ายมาวางที่ `docs/training/videos/live-clicks/` เพื่อให้ index นี้ลิงก์ถึง
