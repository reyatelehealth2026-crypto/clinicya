## บทพูดเต็มแบบอ่านต่อเนื่อง

### ช่วงเปิด

สวัสดีครับ คลิปนี้จะพาเชื่อม LINE Official Account ของร้านเข้ากับระบบ REYA แบบทีละขั้น  
เหมาะสำหรับเจ้าของร้านหรือแอดมินที่อยากตั้งค่าเอง โดยไม่ต้องมีพื้นฐานเทคนิค  
ถ้าทำตามครบทุกขั้น ร้านจะรับแชทลูกค้าผ่าน REYA ได้ทันที

### ช่วงเตรียมตัว

ก่อนเริ่ม ขอให้เตรียม 4 อย่าง  
หนึ่ง อินเทอร์เน็ตและคอมพิวเตอร์หรือมือถือ  
สอง บัญชี LINE ส่วนตัวที่ใช้ล็อกอินระบบของ LINE  
สาม LINE Official Account ของร้าน ถ้ายังไม่มี เดี๋ยวเราสร้างให้ในขั้นแรก  
สี่ เข้าระบบ REYA ของร้านได้เรียบร้อย

### ช่วงสร้าง LINE OA

ถ้ายังไม่มี LINE OA ให้เข้า manager.line.biz แล้วกดสร้างบัญชีใหม่  
กรอกชื่อร้าน เลือกประเภทธุรกิจให้ตรงกับร้านยา แล้วทำตามขั้นตอนจนได้บัญชีของร้าน  
เมื่อเสร็จแล้ว ให้จำ Basic ID ที่ขึ้นต้นด้วยเครื่องหมาย @ ไว้ เพราะอีกเดี๋ยวเราจะใช้กรอกใน REYA

### ช่วงเปิด LINE Developers

ต่อไปเข้า developers.line.biz/console  
ใช้บัญชี LINE เดียวกับที่สร้าง OA เมื่อสักครู่  
ถ้ายังไม่มี Provider ให้สร้างก่อน โดยใช้ชื่อร้านหรือชื่อบริษัทก็ได้  
หลังจากนั้นกด Create a Messaging API channel แล้วเลือก OA ของร้านให้ถูกต้อง

### ช่วงคัดลอกรหัส 3 ตัว

ตอนนี้เราจะคัดลอกรหัสสำคัญ 3 ตัว  
ตัวแรกคือ Channel ID  
ตัวที่สองคือ Channel Secret  
และตัวที่สามคือ Channel Access Token  
สองตัวแรกจะอยู่ในแท็บ Basic settings  
ส่วน Access Token จะอยู่ในแท็บ Messaging API และบางครั้งต้องกดปุ่ม Issue ก่อน  
แนะนำให้คัดลอกแล้วพักไว้ในที่ปลอดภัยชั่วคราว เพื่อจะเอาไปวางใน REYA ให้ครบ

### ช่วงกรอกใน REYA

กลับมาที่ REYA ของร้าน  
เข้าเมนูตั้งค่า แล้วเลือกแท็บ LINE  
กดเพิ่มบัญชี LINE  
จากนั้นกรอกชื่อบัญชีเพื่อให้ทีมจำได้ง่าย  
กรอก Basic ID ของร้าน  
แล้ววาง Channel ID, Channel Secret และ Channel Access Token ให้ครบ  
ถ้ากรอกครบแล้ว กดบันทึกได้เลย

### ช่วงตั้ง Webhook

หลังบันทึก ระบบจะสร้าง Webhook URL ให้ทันที  
ให้กดคัดลอก URL นี้  
จากนั้นกลับไปที่ LINE Developers ในแท็บ Messaging API  
วางลงในช่อง Webhook URL แล้วกด Update  
ต่อด้วยเปิด Use webhook  
และปิด Auto-reply messages กับ Greeting messages  
สองจุดนี้สำคัญมาก เพราะถ้ายังเปิดอยู่ LINE จะตอบเองแทน REYA

### ช่วงทดสอบ

เมื่อกลับมาที่ REYA ให้กดปุ่มทดสอบที่การ์ดบัญชี LINE  
ถ้าขึ้นว่าเชื่อมต่อสำเร็จ พร้อมชื่อ OA ของร้าน แปลว่าพร้อมใช้งานแล้ว  
หลังจากนั้นสามารถลองทัก OA ของร้านจาก LINE จริงอีกครั้ง เพื่อเช็กว่าข้อความเข้ามาใน Inbox ของ REYA ได้ครบ

### ช่วงปิดท้าย

ถ้าเจอปัญหา เช่น ทดสอบไม่ผ่าน หรือบอทไม่ตอบ  
ส่วนใหญ่เกิดจาก Access Token คัดลอกไม่ครบ, วาง Webhook URL ไม่ถูก หรือยังไม่ได้เปิด Use webhook  
สามารถย้อนดูคู่มือเต็มที่หน้า help/line-setup.html ได้ทุกเมื่อ  
หรือส่งภาพหน้าจอที่ติดปัญหามาให้ทีม REYA ช่วยต่อได้เลย

## รายการ annotation ที่ทีมตัดต่อควรเตรียม

- หมุดตัวเลข `1`, `2`, `3` สำหรับชี้ตำแหน่ง Channel ID / Secret / Token
- กรอบไฮไลต์สีเขียวสำหรับปุ่มหลัก เช่น `Create`, `Issue`, `บันทึก`, `ทดสอบ`
- สวิตช์ตัวอย่าง `Use webhook = เปิด`
- สวิตช์ตัวอย่าง `Auto-reply = ปิด`
- lower-third สั้น 5 อัน:
  - `ขั้น 1 สร้าง LINE OA`
  - `ขั้น 2 เปิด LINE Developers`
  - `ขั้น 3 คัดลอกรหัส 3 ตัว`
  - `ขั้น 4 กรอกใน REYA`
  - `ขั้น 5 ตั้ง Webhook และทดสอบ`
