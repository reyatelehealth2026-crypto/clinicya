## ขั้นที่ 1: เลือกแชทลูกค้า
เปิด `/inbox-v2` แล้วเลือกแชทของลูกค้าที่ต้องการจ่ายยา
> 💡 ใช้ filter "ยังไม่ตอบ" เพื่อหาลูกค้าที่รออยู่ก่อน

## ขั้นที่ 2: กดปุ่ม "💊 จ่ายยา"
ปุ่มอยู่ใน toolbar ด้านบนของแชท จะเปิด modal "จ่ายยา" ขึ้นมา
> 💡 เลือกยาจากคลังสินค้า (business_items) — ระบบจะดึงราคา + stock ให้อัตโนมัติ

## ขั้นที่ 3: กรอกข้อมูลยาให้ครบ
- **จำนวน:** กล่อง/แผงที่จ่าย (ไม่ใช่จำนวนเม็ดรวม) ระบบจะคำนวณ pack_size ให้
- **ขนาดยา:** เม็ดต่อมื้อ (เช่น 1 เม็ด ต่อ มื้อ — ไม่ใช่ยอดรวม!)
- **มื้อ:** ติ๊กเช้า / กลางวัน / เย็น / ก่อนนอน
- **ก่อน/หลังอาหาร:** เลือกให้ตรงตามใบสั่งยา
> ⚠️ ถ้ากรอกจำนวนเม็ดผิด ระบบจะเตือน pack_size warning ก่อนยืนยัน

## ขั้นที่ 4: เลือกวิธีชำระเงิน
- **เงินสด (cash):** ตัด stock ทันที
- **เครดิต (credit):** ตัด stock ทันที + เก็บเงินทีหลัง
- **โอน (transfer):** สร้าง transactions รอตรวจสลิป + ยังไม่ตัด stock
- **จ่ายทีหลัง (later):** สร้าง pending transaction + ยังไม่ตัด stock

## ขั้นที่ 5: กดยืนยัน + ส่งฉลาก
ระบบจะ:
- บันทึก `dispensing_records`
- ส่ง Flex medicine label ผ่าน LINE (carousel หากมียาหลายตัว)
- บันทึก message ลง DB ด้วย `sent_by='system:dispense'`
- เริ่มนับ refill auto-track ตั้งแต่วันนี้
> 💡 ลูกค้าจะได้รับฉลากยาแบบสวยใน LINE ทันที — สามารถกดเพื่อดูวิธีกินยาได้
