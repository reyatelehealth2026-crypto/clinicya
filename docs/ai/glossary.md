# Glossary

- Admin user: tenant staff account stored in `admin_users`, authenticated by `auth/login.php` and `classes/AdminAuth.php`.
- Platform user: SaaS/platform-level user stored in `platform_users`, authenticated by `admin/platform-login.php` or Google OAuth flow.
- Tenant: a shop/business context stored in `tenants`, with database name `tenants.db_name`, used by `Modules\Core\Database::forTenant`.
- LINE account: LINE OA credentials and metadata in `line_accounts`; used to validate webhook signatures and send messages.
- LIFF: LINE Front-end Framework used by `line-mini-app`; configured by LIFF ID and resolved at runtime by `line-mini-app/src/lib/config.ts`.
- Line user ID: LINE user identifier, commonly `line_user_id`, used across users, mini app APIs, reminders, and messages.
- Flex message: LINE rich message payload generated by `classes/FlexTemplates.php`, `BusinessBot`, and AI templates.
- CRM inbox: active admin messaging interface in `inbox-v2.php`, backed by `classes/InboxService.php`.
- Dispense: admin/pharmacist flow in `inbox-v2.php` that writes `dispensing_records`, adjusts stock or creates cart/order rows, and sends medicine label Flex.
- Transaction: order/purchase record in `transactions`, with detail rows in `transaction_items`.
- Payment slip: customer upload record in `payment_slips`; mini app upload path is `api/checkout.php::handleUploadSlip`.
- Points: loyalty balance/history tables such as `points_transactions`, `points_history`, `points_settings`.
- Reward: redeemable loyalty item in `rewards`, with redemptions in `reward_redemptions`.
- Triage session: AI/pharmacy consultation state in `triage_sessions`.
- Red flag: urgent symptom condition handled by AI modules such as `RedFlagDetector` and MIMS/triage services.
- Broadcast: scheduled or queued outbound LINE message handled by broadcast pages/APIs and cron jobs.
- DLQ: dead-letter queue concept used by webhook retry/cleanup scripts.
- Tenant context: per-request routing state controlled by `TenantContext`, sessions, subdomain/account routing, and database factory.
