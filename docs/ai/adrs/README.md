# AI-Inferred ADRs — ไม่ใช่ชุด canonical

> **อ่านก่อน:** ADR ที่โค้ดอ้างถึงจริงอยู่ที่ [`docs/adr/`](../../adr/README.md) ไม่ใช่โฟลเดอร์นี้

## โฟลเดอร์นี้คืออะไร

เป็นส่วนหนึ่งของ [AI knowledge base](../README.md) ที่สร้างเมื่อ 2026-07-03 โดยให้ AI สำรวจโค้ดแล้ว **อนุมาน** ว่ามีการตัดสินใจเชิงสถาปัตยกรรมอะไรบ้าง ทุกไฟล์จึงมีสถานะ `Inferred, needs confirmation.`

**ไม่มีโค้ดใดในรีโปอ้างถึงไฟล์ในโฟลเดอร์นี้เลย**

## เลขชนกับชุด canonical — ระวังสับสน

โฟลเดอร์นี้ใช้รูปแบบ `ADR 0001` (4 หลัก เว้นวรรค) ส่วนโค้ดอ้างด้วยรูปแบบ `ADR-001` (3 หลัก มีขีด) ซึ่งหมายถึงไฟล์ใน `docs/adr/` **เลขตรงกันไม่ได้แปลว่าเรื่องเดียวกัน:**

| เลข | ไฟล์ในโฟลเดอร์นี้ | `docs/adr/` (canonical) |
|---|---|---|
| 0001 | Tenant-Aware Database Routing | Database-per-Tenant Isolation — หัวข้อทับซ้อน แต่ฉบับ canonical กว้างกว่าและมีหัวข้อย่อยที่โค้ดอ้าง |
| 0002 | Shared LINE Mini App Runtime Tenant Resolution | Tenant Provisioning Pipeline — **คนละเรื่องสิ้นเชิง** |
| 0003 | Prefer LINE Reply Then Push Fallback | (สงวนไว้ ยังไม่ทราบหัวข้อเดิม) |

## แล้วไฟล์ในนี้ยังมีประโยชน์ไหม

มี — `0002` และ `0003` บันทึกการตัดสินใจที่ **ยังไม่มี ADR canonical ครอบคลุม**:

- **0002** — Mini App หนึ่ง build เสิร์ฟทุกผู้เช่า resolve tenant/LIFF ตอน runtime ไม่ใช่ build time
- **0003** — ส่ง LINE ด้วย reply token ก่อนเสมอ แล้วค่อย fallback ไป push เพื่อประหยัดโควตา

หากต้องการยกระดับเป็น canonical: ยืนยันเนื้อหากับผู้ตัดสินใจ แล้วเขียนใหม่ใน `docs/adr/` ที่เลข **0007 เป็นต้นไป** (0003–0005 สงวนไว้ให้ ADR ต้นฉบับที่อาจถูกพบภายหลัง)

ดูกติกาทั้งหมดที่ [`docs/adr/README.md`](../../adr/README.md)
