# Re-ya — คลังความรู้ฟีเจอร์ (Feature Knowledge Base)

> แหล่งอ้างอิงสำหรับ agent `crm-marketer` ใช้ "สอน/อธิบายการใช้งานทุกฟีเจอร์" ให้เจ้าของร้านยาและทีมงาน ทั้งระดับพื้นฐานและขั้นสูง
>
> **กฎการใช้:** สอนได้เฉพาะฟีเจอร์ที่อยู่ในไฟล์นี้ ห้ามกุขั้นตอน/ปุ่ม/ฟีเจอร์ที่ไม่มี ถ้าผู้ใช้ถามฟีเจอร์ที่ไม่อยู่ในนี้ ให้บอกตรง ๆ ว่าต้องตรวจสอบกับระบบจริงก่อน อย่าเดา ขั้นตอน UI ที่ระบุเป็นแนวทางตามโครงสร้างเมนู/แท็บที่มีจริง — ถ้าจะอ้างปุ่มเฉพาะเจาะจง ให้ใช้ภาษากลาง ("เปิดแท็บ X แล้วกดเพิ่ม/บันทึก") ไม่ใช่ระบุชื่อปุ่มที่อาจไม่ตรง
>
> ระบบเป็นเมนู sidebar แบ่ง 6 กลุ่มตามบทบาท (super_admin/owner → admin → pharmacist/marketing/tech → staff) หลายหน้ารวมเป็นแท็บเดียว path ใช้ clean URL (ตัด `.php`)

---

## วิธีอ่านไฟล์นี้ (โครงต่อฟีเจอร์)

แต่ละฟีเจอร์มี:
- **เมนู / path** — หาเจอที่ไหน
- **ทำอะไร** — คุณค่าหลักในหนึ่งประโยค
- **ใช้พื้นฐาน** — ขั้นตอนเริ่มต้นสำหรับมือใหม่
- **ขั้นสูง / ใช้แบบโปร** — เทคนิคที่ดึงคุณค่าเพิ่ม
- **บทบาท** — ใครเข้าถึงได้
- **เกี่ยวข้องกับ** — cron/ฟีเจอร์อื่นที่ทำงานร่วมกัน

# กลุ่ม 1 — ภาพรวมและสถิติ (Insights & Overview)

## Dashboard (แดชบอร์ดภาพรวม)
- **เมนู:** `/dashboard` — แท็บ Executive (`?tab=executive`) และ CRM (`?tab=crm`)
- **ทำอะไร:** ดูสุขภาพร้านในหน้าเดียว — ยอดขาย ออเดอร์ จำนวนลูกค้า และมุม CRM (funnel/churn/retention/segment)
- **ใช้พื้นฐาน:** เปิดแท็บ Executive ดู KPI การ์ดด้านบน (รายได้/ออเดอร์/ลูกค้าใหม่) เป็นกิจวัตรเปิดร้านทุกเช้า
- **ขั้นสูง:** ใช้แท็บ CRM อ่าน funnel + retention curve เพื่อหาจุดรั่ว (เช่นลูกค้าซื้อครั้งเดียวแล้วหาย) → ตั้งแคมเปญ win-back ผ่าน Broadcast/Drip ค่า KPI ถูก warm cache ไว้ทุก 15 นาที จึงโหลดไว
- **บทบาท:** Owner, Admin
- **เกี่ยวข้อง:** `cron/dashboard_cache_warming.php`, `dashboard_realtime_updates.php`, `rebuild-customer-projections.php`

## วิเคราะห์ข้อมูล (Analytics)
- **เมนู:** `/analytics`
- **ทำอะไร:** เจาะลึกข้อมูลเชิงสถิติมากกว่าหน้า Dashboard
- **ใช้พื้นฐาน:** เลือกช่วงเวลา ดูแนวโน้มยอดขาย/ลูกค้า
- **ขั้นสูง:** ใช้คู่กับ CRM dashboard เพื่อตัดสินใจสต๊อก/โปรโมชัน
- **บทบาท:** Owner, Admin

## ประวัติการใช้งาน (Activity Logs)
- **เมนู:** `/activity-logs`
- **ทำอะไร:** บันทึกการกระทำของทีมงานทุกคน (ใครแก้อะไร เมื่อไหร่) — audit trail
- **ใช้พื้นฐาน:** กรองตามผู้ใช้/วันที่/ประเภทการกระทำ
- **ขั้นสูง:** ใช้ตรวจสอบเมื่อข้อมูลผิดปกติ หรือสอบทานความรับผิดชอบของทีม
- **บทบาท:** Owner เท่านั้น

# กลุ่ม 2 — งานบริการคลินิก (Clinical Services)

## ห้องยา / จ่ายยา (Pharmacy)
- **เมนู:** `/pharmacy` — 5 แท็บ: Dashboard, Pharmacists, Drug Interactions, Dispense
- **ทำอะไร:** ศูนย์งานเภสัชกร — ตารางเวร สถิติการจ่ายยารายวัน ฐานข้อมูลปฏิกิริยายา และบันทึกการจ่ายยา
- **ใช้พื้นฐาน:** แท็บ Dispense บันทึกการจ่ายยา (จำนวน วันเติมยาถัดไป โน้ตผู้ป่วย); แท็บ Pharmacists เพิ่ม/แก้เภสัชกรและเวร
- **ขั้นสูง:** ดูแลฐาน Drug Interactions ให้ครบเพื่อให้การ์ดเตือนปฏิกิริยายาทำงานแม่นในแชต AI; ใช้สถิติ dispense วางแผนสต๊อกยาที่จ่ายบ่อย
- **บทบาท:** Owner, Admin, Pharmacist
- **เกี่ยวข้อง:** dispense flow ใน inbox-v2 (Flex medicine label), `dispense-tracking`

## ติดตามการจ่ายยา (Dispense Tracking)
- **เมนู:** `/dispense-tracking`
- **ทำอะไร:** ตามว่าลูกค้าคนไหนยาใกล้หมด ต้องเติมยา (อิงประวัติการจ่าย)
- **ใช้พื้นฐาน:** เปิดรายการติดตาม เห็นลูกค้า–ยา–จำนวนที่จ่าย–วันคาดว่าหมด; กดส่งเตือนเติมยาทาง LINE เองได้
- **ขั้นสูง:** ปล่อยให้ cron ส่งเตือนอัตโนมัติล่วงหน้า ~3 วันก่อนยาหมด → สร้างยอดขายซ้ำสม่ำเสมอ (ฟีเจอร์ retention ที่ทำเงินที่สุดของร้านยา) จับคู่กับ points/rewards เพื่อกระตุ้นการกลับมาเติม
- **บทบาท:** Pharmacist, Owner, Admin
- **เกี่ยวข้อง:** `cron/medication_refill_reminder.php`

## นัดหมาย (Appointments)
- **เมนู (แอดมิน):** `/appointments-admin` | **(ลูกค้า):** Mini App `/appointments`
- **ทำอะไร:** จองและจัดการนัดปรึกษากับเภสัชกร (รวมนัด video call)
- **ใช้พื้นฐาน:** สร้าง/แก้/ลบนัด อัปเดตสถานะ (รอ → ยืนยัน → กำลังดำเนินการ → เสร็จ/ไม่มา) ใส่โน้ตและเรตติ้ง
- **ขั้นสูง:** ระบบส่งเตือนอัตโนมัติ 2 จังหวะ (ก่อนนัด 10 นาที + ตอนถึงเวลา) พร้อมลิงก์เข้า video call; ใช้นัดเป็นบริการพรีเมียมเพิ่มมูลค่า/สร้างความผูกพัน
- **บทบาท:** Owner, Admin, Pharmacist, Staff
- **เกี่ยวข้อง:** `cron/appointment_reminder.php` (ทุกนาที)

## ปรึกษาออนไลน์ / Video Call (Telepharmacy)
- **เมนู (แอดมิน):** `/pharmacist-video-calls` | **(ลูกค้า):** Mini App `/video`
- **ทำอะไร:** นัดและทำ video consultation กับลูกค้า
- **ใช้พื้นฐาน:** ดูรายการนัดที่ถึงคิว เริ่มลิงก์วิดีโอ จบสาย
- **ขั้นสูง:** ใช้เป็นจุดขายเรื่องการเข้าถึง (ลูกค้าปรึกษาเภสัชกรจากบ้านได้) ต่อยอดเป็นบริการเก็บค่าปรึกษาหรือแพ็กเกจดูแลโรคเรื้อรัง
- **บทบาท:** Pharmacist, Staff

# กลุ่ม 3 — ดูแลลูกค้า (Patient Care & CRM)

## กล่องข้อความ / Inbox CRM HUD (Vibe Selling OS v2)
- **เมนู:** `/inbox-v2`
- **ทำอะไร:** กล่องแชตรวมทุกบทสนทนา LINE พร้อม CRM HUD (customer 360, tags, notes) และโมดัลจ่ายยา
- **ใช้พื้นฐาน:** อ่าน/ตอบแชตลูกค้า จัดกลุ่มตามคน ค้นหา/กรอง; เปิด HUD ข้างขวาดูโปรไฟล์ลูกค้า ใส่แท็ก/โน้ต
- **ขั้นสูง:** ใช้ dispense modal จ่ายยาในแชตเลย (ออก Flex medicine label อัตโนมัติ + บันทึกลง record); ใช้ tags ระหว่างคุยเพื่อ segment ทันที (เช่นแท็ก "ความดัน"); ติดตาม response-time KPI เพื่อพัฒนาทีม
- **บทบาท:** Owner, Admin, Pharmacist, Staff
- **เกี่ยวข้อง:** `cron/inbox-response-time-collector.php`, `ai_session_summarizer.php`

## รายชื่อลูกค้า (Customers / Users)
- **เมนู:** `/users`
- **ทำอะไร:** ฐานลูกค้า (ผู้ติดตาม LINE) ค้นหา กรอง ติดแท็กแบบกลุ่ม
- **ใช้พื้นฐาน:** ค้นชื่อ/เบอร์ กรองตามระดับสมาชิก/ประวัติซื้อ/ความเคลื่อนไหว
- **ขั้นสูง:** ติดแท็กแบบ bulk เพื่อทำ segment (เช่น "สูงอายุ", "เบาหวาน") แล้วยิง Broadcast เฉพาะกลุ่ม; ทำ RFM segment (ซื้อล่าสุด/ถี่/ยอด) เพื่อแยกลูกค้า VIP กับลูกค้าเสี่ยงหลุด; export รายชื่อได้
- **บทบาท:** Pharmacist, Owner, Admin
- **เกี่ยวข้อง:** User Tags (`/user-tags`), Odoo sync (ถ้าเปิด)

## แท็กลูกค้า (User Tags)
- **เมนู:** `/user-tags` (หรือในหน้า `/users`)
- **ทำอะไร:** สร้าง/จัดการหมวดแท็กสำหรับ segment ลูกค้า
- **ใช้พื้นฐาน:** สร้างแท็ก ติดให้ลูกค้า
- **ขั้นสูง:** วาง "tag scheme" เป็นระบบ (ตามโรค/ตามพฤติกรรม/ตาม lifecycle) เพื่อให้ broadcast แม่นยำ — สอนเป็น playbook ได้ดี
- **บทบาท:** Pharmacist, Owner, Admin

## บรอดแคสต์ (Broadcast)
- **เมนู:** `/broadcast` — 4 แท็บ: Send, Catalog Builder, Products, Stats
- **ทำอะไร:** ส่งข้อความหาลูกค้าจำนวนมาก (ข้อความ/Flex/รูป) พร้อมวัดผล
- **ใช้พื้นฐาน:** แท็บ Send เขียนข้อความ เลือกกลุ่มเป้าหมายตามแท็ก/ระดับ แล้วส่งหรือตั้งเวลา
- **ขั้นสูง:** Catalog Builder ทำแคตตาล็อกริชมีเดีย; Products auto-send โปรตามแท็ก (เช่นแท็ก "ความดัน" → ส่งยาที่เกี่ยวข้อง); แท็บ Stats อ่าน delivery/open/click เพื่อ A/B test; ส่งแบบ symptom/condition-based เพื่อ relevance สูง
- **บทบาท:** Admin, Marketing
- **เกี่ยวข้อง:** `cron/process_broadcast_queue.php` (Multicast 500/แบตช์), `broadcast_delivery_reconcile.php`
- **หมายเหตุ:** ถ้าจะ "ส่งจริง" ให้ส่งต่อ skill `/line-broadcast` (cache-first, 2-up Flex, มีขั้นอนุมัติในแชต) — agent นี้ร่างข้อความ ไม่กดส่งเอง

## ระบบสมาชิก / แต้ม & รางวัล (Membership & Rewards)
- **เมนู (แอดมิน):** `/membership` — 3 แท็บ: Members, Rewards, Points Settings | **(ลูกค้า):** Mini App `/rewards`
- **ทำอะไร:** ระบบสะสมแต้ม ระดับสมาชิก และของรางวัล
- **ใช้พื้นฐาน:** ดูรายชื่อสมาชิก/ระดับ/แต้มสะสม; เพิ่ม/แลกแต้มให้ลูกค้าด้วยมือ
- **ขั้นสูง:** ตั้งกติกาได้แต้ม (เช่น 1 บาท = 1 แต้ม, โบนัสแนะนำเพื่อน), ตั้งของรางวัลแบบมีระดับ + จำกัดสต๊อก, ตั้งวันหมดอายุแต้ม; ออกแบบ "loyalty loop" ให้ลูกค้ากลับมาซื้อ; ฝั่งลูกค้าแลกแต้มเองใน Mini App
- **บทบาท:** ทุกบทบาททีมงาน
- **เกี่ยวข้อง:** `cron/reward_expiry_reminder.php`

## ดริปแคมเปญ (Drip Campaigns)
- **เมนู:** `/drip-campaigns`
- **ทำอะไร:** ลำดับข้อความอัตโนมัติแบบ nurture (เช่นหลังซื้อครั้งแรก → ตามผล Day 0/3/7)
- **ใช้พื้นฐาน:** สร้างแคมเปญ ตั้ง trigger + ดีเลย์ระหว่างข้อความ เปิด/ปิดได้
- **ขั้นสูง:** ออกแบบ journey หลายสเต็ป (ต้อนรับ → ให้ความรู้ → เสนอขาย → ขอรีวิว); จับคู่ trigger กับพฤติกรรม (ติดตามใหม่/ซื้อครั้งแรก/ไม่เคลื่อนไหว) เพื่อ activate และ retain อัตโนมัติ
- **บทบาท:** Admin, Marketing
- **เกี่ยวข้อง:** `cron/process_drip_campaigns.php` (ทุก 5 นาที)

## ข้อความ/รายงานตามเวลา (Scheduled)
- **เมนู:** `/scheduled` — 2 แท็บ: Messages, Reports
- **ทำอะไร:** ตั้งเวลาส่งบรอดแคสต์ล่วงหน้า + ตั้งรายงานอัตโนมัติส่งทาง LINE
- **ใช้พื้นฐาน:** ตั้งข้อความให้ส่ง "พรุ่งนี้ 9 โมง"
- **ขั้นสูง:** ตั้งรายงานยอดขายรายวัน/สัปดาห์ส่งเข้า LINE ผู้บริหารอัตโนมัติ
- **บทบาท:** Admin, Marketing
- **เกี่ยวข้อง:** `cron/scheduled_reports.php`, `process_broadcast_queue.php`

## ตอบกลับอัตโนมัติ (Auto-Reply)
- **เมนู:** `/auto-reply`
- **ทำอะไร:** กฎตอบกลับตามคีย์เวิร์ด (เช่น "สวัสดี" → ข้อความต้อนรับ)
- **ใช้พื้นฐาน:** เพิ่ม/แก้/ลบ trigger คีย์เวิร์ด + ข้อความตอบ
- **ขั้นสูง:** วางคีย์เวิร์ดครอบคำถามยอดฮิต (เวลาทำการ/วิธีสั่ง/โปรโมชัน) เพื่อลดงานแชตซ้ำ ๆ
- **บทบาท:** Pharmacist, Staff

# กลุ่ม 4 — คลังสินค้าและยอดขาย (Supply & Revenue)

## POS ขายหน้าร้าน (Point of Sale)
- **เมนู:** `/pos`
- **ทำอะไร:** ขายหน้าเคาน์เตอร์ (เลือกสินค้า คิดเงิน รับชำระ)
- **ใช้พื้นฐาน:** เลือกสินค้า ใส่ส่วนลด รับชำระ พิมพ์ใบเสร็จ
- **ขั้นสูง:** เชื่อมยอด POS กับสต๊อกและฐานลูกค้าเดียวกับ LINE (ออมนิแชนเนล) — ลูกค้าซื้อหน้าร้านก็สะสมแต้มได้
- **บทบาท:** Staff, Admin

## รายการสั่งซื้อ (Orders)
- **เมนู:** `/shop/orders`
- **ทำอะไร:** จัดการออเดอร์จากร้านออนไลน์
- **ใช้พื้นฐาน:** ดู/อัปเดตสถานะออเดอร์ จัดส่ง
- **ขั้นสูง:** ใช้คู่กับ refill reminder และ wishlist/restock เพื่อปิดการขายซ้ำ
- **บทบาท:** Owner, Admin, Staff

## คลังสินค้า (Inventory) — ฮับสินค้า/สต๊อก
- **เมนู:** `/inventory` — หลายแท็บ: Storefront, Stock, Movements, Adjustment, Low-Stock, Locations, Batch/Lot, Put-Away, Drug Groups, Generic Names, Label Templates, Drug Interactions, Reports (WMS)
- **ทำอะไร:** ศูนย์รวมจัดการสินค้า/สต๊อก/คลัง รวมข้อมูลเภสัช (กลุ่มยา/ชื่อสามัญ/ฉลาก/ปฏิกิริยายา)
- **ใช้พื้นฐาน:** แท็บ Storefront แก้รายละเอียดสินค้า ราคา รูป หมวด; แท็บ Stock ดูสต๊อกตามที่เก็บ
- **ขั้นสูง:** ตั้ง ROP ที่แท็บ Low-Stock เพื่อเตือนสั่งซื้อ; ใช้ Batch/Lot คุมวันหมดอายุยา; Put-Away จัดของเข้าตำแหน่ง; Reports ดูมูลค่าสต๊อก/turnover/aging; ทำ Label Templates ฉลากยาเฉพาะร้าน
- **บทบาท:** Admin, Pharmacist, Staff
- **หมายเหตุ:** `/products.php` เป็นแค่ redirect มาที่นี่ — UI สินค้าจริงอยู่ที่ `/inventory`
- **เกี่ยวข้อง:** `cron/refresh_product_cache.php`, `sync-retail-products.php`, `sync_cny_products.php`

## จัดซื้อ (Procurement)
- **เมนู:** `/procurement` — 3 แท็บ: Purchase Orders, Goods Receive, Suppliers
- **ทำอะไร:** สั่งซื้อจากซัพพลายเออร์ รับของ จัดการคู่ค้า
- **ใช้พื้นฐาน:** สร้าง PO ติดตามสถานะส่ง รับของ (GR) จัดการรายชื่อซัพพลายเออร์
- **ขั้นสูง:** เชื่อม Low-Stock → PO ให้เติมสต๊อกทันเวลา; คุม payment terms ของซัพพลายเออร์ผ่าน AP ในบัญชี
- **บทบาท:** Owner, Admin

## บัญชี (Accounting)
- **เมนู:** `/accounting` — 4 แท็บ: Dashboard, AP, AR, Expenses
- **ทำอะไร:** การเงินร้าน — เจ้าหนี้ ลูกหนี้ ค่าใช้จ่าย กระแสเงินสด
- **ใช้พื้นฐาน:** บันทึกใบแจ้งหนี้ ติดตามการชำระ ดู aging
- **ขั้นสูง:** ใช้ Dashboard ดูภาพรวม AP/AR/cash flow เพื่อวางแผนสภาพคล่อง
- **บทบาท:** Owner, Admin

## เอกสาร / VAT (Documents)
- **เมนู:** `/documents`
- **ทำอะไร:** ชุดเอกสารบัญชีไทย (ใบเสนอราคา/ใบวางบิล/ใบกำกับภาษี/ใบเสร็จ/PO/GR/ใบเพิ่ม-ลดหนี้) เลขรันอัตโนมัติ + คำนวณ VAT
- **ใช้พื้นฐาน:** ออก/ดู/พิมพ์เอกสารขายและซื้อ พิมพ์ใบเสร็จที่ถูกต้องตาม VAT
- **ขั้นสูง:** ใช้ register สำหรับยื่นภาษี; ดึงข้อมูลภาษีร้านจาก shop_settings มาออกเอกสารอัตโนมัติ — ขายจุดนี้กับร้านที่จด VAT ได้ดี
- **บทบาท:** Owner, Admin

## Odoo Dashboard (เฉพาะร้านที่เปิด Odoo)
- **เมนู:** `/odoo-dashboard`
- **ทำอะไร:** ข้อมูลขายจาก Odoo ERP ที่ sync มา
- **ใช้พื้นฐาน:** ดูยอดขาย/ออเดอร์/ลูกค้าจาก Odoo
- **ขั้นสูง:** reconcile ยอด Odoo กับออเดอร์ LINE
- **บทบาท:** Owner, Admin (เห็นต่อเมื่อ `ODOO_INTEGRATION_ENABLED`)
- **เกี่ยวข้อง:** `cron/sync_odoo_dashboard_cache.php`, Sync Dashboard (`/sync-dashboard`)

# กลุ่ม 5 — ตั้งค่าร้านค้า (Facility Setup)

## ตั้งค่าระบบ (Settings)
- **เมนู:** `/settings` — หลายแท็บ: LINE, General, Shop Info/TAX, Welcome, LIFF, Vibe Selling v2, Telegram, Email/SMTP, Notifications, Consent (PDPA), Quick Access
- **ทำอะไร:** ศูนย์ตั้งค่าทั้งระบบ
- **ใช้พื้นฐาน:**
  - **LINE:** ลงทะเบียน/จัดการ LINE OA หลายบัญชี ดูโควต้า API
  - **Shop Info/TAX:** ชื่อร้าน ที่อยู่ เลข VAT ค่าส่ง/ส่งฟรีขั้นต่ำ วิธีชำระ (COD/โอน/PromptPay) โลโก้
  - **Welcome:** ข้อความต้อนรับเมื่อมีคนแอดบอท
  - **LIFF:** ลงทะเบียน LIFF ID ของ Mini App
- **ขั้นสูง:** **Quick Access** ปักหมุดเมนูที่ใช้บ่อย; **Consent/PDPA** เปิดฟอร์มขอความยินยอม; **Notifications** เปิด/ปิดชนิดแจ้งเตือน; **Vibe Selling v2** ตั้งค่า inbox + AI copilot; **Email/SMTP** อีเมลธุรกรรม; **Telegram** แจ้งเตือนเสริม
- **บทบาท:** Owner, Admin, Tech

## ตั้งค่าร้านออนไลน์ (Mini App Settings)
- **เมนู:** `/admin/miniapp-settings.php`
- **ทำอะไร:** ตั้งค่าหน้าร้านออนไลน์ใน LINE Mini App
- **ใช้พื้นฐาน:** ปรับการแสดงผล/เนื้อหาหน้าร้าน
- **บทบาท:** Owner, Admin

## Landing Page
- **เมนู:** `/admin/landing-settings` — แท็บ: Banners, Featured Products, Articles, SEO, FAQ, Testimonials, Trust Badges, Custom HTML
- **ทำอะไร:** จัดการหน้าแลนดิ้งสาธารณะของร้าน
- **ใช้พื้นฐาน:** ใส่แบนเนอร์ เลือกสินค้าแนะนำ เขียน FAQ
- **ขั้นสูง:** ใช้แท็บ SEO (meta/OG/schema) ให้ติดค้นหา; Articles เขียนคอนเทนต์สุขภาพดึง organic traffic; Testimonials + Trust Badges สร้างความน่าเชื่อถือเพื่อเพิ่ม conversion
- **บทบาท:** Owner, Admin

## Rich Menu (เมนูลัด LINE)
- **เมนู:** `/rich-menu` — 3 แท็บ: Static, Dynamic, Switch
- **ทำอะไร:** เมนูภาพด้านล่างแชต LINE
- **ใช้พื้นฐาน:** แท็บ Static วางปุ่มเมนูคงที่ ลิงก์ไปสินค้า/URL/LIFF แล้ว publish
- **ขั้นสูง:** Dynamic แสดงเมนูต่างกันตามเงื่อนไข (เช่น VIP เห็นเมนูพิเศษ); Switch ทำเมนูหลายหน้าให้ปัดสลับหมวด — ออกแบบ rich menu ให้เป็น "ทางลัดสู่ยอดขาย" (สั่งซื้อ/นัด/แลกแต้ม)
- **บทบาท:** Admin, Marketing
- **เกี่ยวข้อง:** Templates (`/templates`), Flex Builder (`/flex-builder`)

- **ขั้นสูง:** ให้สิทธิ์เข้าถึงเฉพาะบัญชี LINE (รองรับหลายสาขา/หลายแบรนด์); ดู last login/activity

# ฟีเจอร์ฝั่งลูกค้า — LINE Mini App (Next.js)

> path ใน `line-mini-app/` — นี่คือประสบการณ์ LIFF ที่ deploy จริง

| ฟีเจอร์ | route | ลูกค้าทำอะไร |
|--------|-------|--------------|
| หน้าแรก | `/` | ดูแบนเนอร์/สินค้าแนะนำ ลัดไปส่วนต่าง ๆ |
| ร้านค้า | `/shop` | เลือกดูสินค้า ค้นหา กรองหมวด/ราคา ใส่ตะกร้า |
| รายละเอียดสินค้า | `/shop/product?id=` | ดูรายละเอียด ใส่ตะกร้า/wishlist รีวิว |
| ตะกร้า | `/cart` | แก้จำนวน ใส่โค้ดส่วนลด ไปชำระเงิน |
| ชำระเงิน | `/checkout` | เลือกที่อยู่/ขนส่ง/วิธีชำระ (COD/PromptPay/โอน) สั่งซื้อ |
| ออเดอร์ | `/orders`, `/order?id=` | ดู/ติดตามออเดอร์ ดาวน์โหลดใบเสร็จ ขอคืนเงิน รีวิว |
| แต้ม/รางวัล | `/rewards`, `/rewards/history` | ดูแต้ม/ระดับ แลกรางวัล ดูประวัติแต้ม |
| Wishlist | `/wishlist` | บันทึกสินค้า รับเตือนราคาลด/ของเข้า |
| นัดหมาย | `/appointments` | จอง/เลื่อน/ยกเลิกนัด เข้าวิดีโอคอล |
| แจ้งเตือน/เตือนกินยา | `/notifications` | ดูแจ้งเตือน จัดการเตือนกินยา |
| โปรไฟล์ | `/profile` | แก้ข้อมูล จัดการที่อยู่/การแจ้งเตือน |
| สมัครสมาชิก | `/register` | ลงทะเบียน ยอมรับ PDPA |
| แชต AI | `/ai-chat` | ปรึกษาอาการ/ยา ขอให้ส่งต่อเภสัชกร |
| สุขภาพ | `/health` | บันทึกแพ้ยา/โรคประจำตัว ดูประวัติปรึกษา |

**AIChat consultation pipeline (จุดขายสำคัญ):** triage อาการ → การ์ดเตือน drug-interaction/red-flag → ส่งต่อเภสัชกรเวรอัตโนมัติเมื่อพบเคสด่วน — สื่อสารเสมอว่า AI เป็น "ตัวช่วยเภสัชกร" ไม่ใช่แทนหมอ

# ระบบอัตโนมัติเบื้องหลัง (Cron) ที่ลูกค้าเห็นผล

| งาน | ไฟล์ | ทำให้เกิดอะไรกับลูกค้า |
|-----|------|------------------------|

| เตือนเติมยา | `cron/medication_refill_reminder.php` | เตือนล่วงหน้า ~3 วันก่อนยาหมด + ลิงก์สั่ง |
| เตือนนัด | `cron/appointment_reminder.php` | เตือนก่อนนัด 10 นาที + ตอนถึงเวลา พร้อมลิงก์วิดีโอ |
| คิวบรอดแคสต์ | `cron/process_broadcast_queue.php` | ส่งบรอดแคสต์เป็นแบตช์ (Multicast 500/ครั้ง) |
| ดริปแคมเปญ | `cron/process_drip_campaigns.php` | ส่งสเต็ปถัดไปของ journey อัตโนมัติ |
| เตือนแต้มหมดอายุ | `cron/reward_expiry_reminder.php` | เตือนลูกค้าก่อนแต้มหมดอายุ |
| ของเข้าสต๊อก | `cron/restock_notification.php` | เตือนเมื่อสินค้าที่หมด/อยู่ใน wishlist กลับมามี |
| ราคาลด wishlist | `cron/wishlist_notification.php` | เตือนราคาลด/ของเข้าสำหรับสินค้าใน wishlist |
| รายงานอัตโนมัติ | `cron/scheduled_reports.php` | ส่งสรุปยอดขาย/กิจกรรมเข้า LINE ผู้บริหาร |
| ลูกค้าหายไป | `cron/check_inactive_users.php` | ติดแท็กลูกค้าไม่เคลื่อนไหวเพื่อทำ win-back |

> หมายเหตุ: รายการ cron ฝั่งหลังบ้านอื่น ๆ (sync, cache, security, reconcile) มีอยู่จริงแต่ไม่เกี่ยวกับการสอนเจ้าของร้านโดยตรง — อ้างถึงเฉพาะเมื่อถูกถามเชิงเทคนิค

# มุมสอน "ใช้แบบโปร" ที่ขายเป็นคอนเทนต์ได้ดี (Learning Ladder)

ไล่ลำดับจากง่าย → สร้างรายได้/รักษาลูกค้า:
1. **พื้นฐาน:** ตั้งค่าร้าน (Shop Info/TAX, Welcome, LIFF) → เปิด Rich Menu → ลงสินค้าใน Inventory/Storefront
2. **เริ่มขาย:** เปิด Mini App shop + checkout → จัดการ Orders → ออกเอกสาร/VAT
3. **เก็บฐานลูกค้า:** ใช้ Inbox HUD ใส่ tags/notes → จัด segment ใน Users/User Tags
4. **กระตุ้นซื้อซ้ำ:** Broadcast ตามแท็ก → Membership/แต้ม → Drip campaigns
5. **รักษาลูกค้าโรคเรื้อรัง (ทำเงินสุด):** Dispense tracking + เตือนเติมยาอัตโนมัติ + เตือนกินยา + นัด/วิดีโอคอล
6. **โตด้วยข้อมูล:** อ่าน CRM dashboard/Analytics → ทำ win-back ลูกค้าหายไป → A/B test broadcast จาก Stats

ทุกหัวข้อข้างบนสอนเป็นโพสต์เดียวจบได้ตามสูตร: **ปัญหา → ตั้งค่าเป็นขั้น → ตัวอย่างร้านจริง → ผลที่จะได้ → ทิปต่อยอดสู่ฟีเจอร์ถัดไป**
